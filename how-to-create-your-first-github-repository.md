
# How to Create Your First GitHub Repository

## Overview

This guide explains how to create a GitHub repository and add a README file. It is designed for people who are new to GitHub and have little or no experience creating repositories.

By the end of this guide, you will have a GitHub repository that you can use to store and organize files for a project.

---

## What You'll Need

Before beginning this guide, make sure you have:

- A GitHub account
- Access to a web browser
- An internet connection

---

## What Is a GitHub Repository?

A repository, often called a "repo," is a location on GitHub where you can store and organize files for a project.

Repositories can be used for many different types of projects, including:

- Software projects
- Writing projects
- Documentation
- Research projects
- Portfolios

---

## Step 1: Sign In to GitHub

1. Open [GitHub](https://github.com/) in your web browser.
2. Select **Sign in**.
3. Enter your GitHub username or email address.
4. Enter your password.
5. Select **Sign in**.

> **Tip:** If you do not already have a GitHub account, select **Sign up** and follow GitHub's instructions to create one.

## Step 2: Create a New Repository

After signing in:

1. Select the **+** icon in the upper-right corner of the GitHub page.
2. Select **New repository**.
3. Enter a name for your repository in the **Repository name** field.
4. Add a short description of your project.
5. Select **Public** if you want other people to be able to view your repository.
6. Select **Add a README file**.
7. Select **Create repository**.

### Choosing a Repository Name

Choose a name that clearly describes the purpose of your repository.

For example:

- `writing-portfolio`
- `technical-writing-samples`
- `linguistics-project`

Avoid names that are difficult to understand or contain unnecessary characters.

## Step 3: Add a README File

A README file provides information about the contents and purpose of a repository.

When creating your repository, select:

**Add a README file**

GitHub will automatically create a file called `README.md`.

The `.md` extension indicates that the file uses **Markdown**, a simple formatting language that allows you to add headings, lists, links, and other formatting to text.
