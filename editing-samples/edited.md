# How to Create a GitHub Repository

A GitHub repository stores your code, files, and project documentation. Repositories also make it easier to collaborate with others.

## Prerequisites

You need a GitHub account to create a repository. If you don't have an account, create one before following these steps.

## Create a Repository

1. Go to [GitHub](https://github.com/) and sign in to your account.

2. In the upper-right corner, select **+**, then select **New repository**.

3. Enter a name for your repository. Choose a name that clearly describes the project's purpose.

4. Optionally, add a description to explain what the repository contains.

5. Choose a visibility setting:
   - **Public:** Anyone can view the repository.
   - **Private:** Only you and people you grant access to can view the repository.

6. Select **Add a README file** if you want GitHub to create a README file for your repository. A README provides information about the project and helps visitors understand its contents.

7. Select **Create repository**.

Your GitHub repository is now ready. You can begin adding files, writing documentation, and managing your project.
